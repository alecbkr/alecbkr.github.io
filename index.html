PRISM - SHADER SANDBOX

A shader development environment built on a custom OpenGL rendering engine. Prism abstracts rendering and resource management while maintaining direct access to OpenGL's programmable pipeline. This streamlines the process of writing, testing, and debugging GLSL shader programs through a unified interface that combines a real-time 3D viewport, code editor, console, and asset manager/importer.

SIMPLETON CHESS

Simpleton Chess is a lightweight console chess game that demonstrates efficient game-state management and move validation in a text-based environment. The game draws a custom ASCII board, enforces the rules of chess through legal move checking, and improves player interaction with visual indicators that highlight every valid move available to the selected piece.
